# RABI3 Gaming Guide — Android MVP

تطبيق Android تجريبي لعملاء شركة الربيع لأجهزة الألعاب، بواجهة عربية RTL وهوية كحلي وبرتقالي. يحتوي على دليل إرشادات PlayStation، مساعد تشخيص أولي للأعطال، معلومات الفروع، ونموذج تجهيز ملخص طلب الصيانة.

> **الحالة:** مصدر مشروع جاهز للبناء. لم يتم إرفاق APK مبني أو اختباره فعليًا. العلامة الظاهرة مؤقتة وليست ملف الشعار الأصلي لشركة الربيع.

## المزايا الحالية
- واجهة عربية متجاوبة تعمل داخل تطبيق Android.
- مكتبة إرشادات مع بحث وتصنيف.
- تشخيص تفاعلي لمشاكل الطاقة والصورة والذراع والحرارة والتخزين.
- أقسام الفروع: سموحة، سان ستيفانو، ميامي.
- نموذج يجهّز ملخص طلب صيانة محليًا ويتيح نسخه.
- ملفات الواجهة مضمّنة داخل التطبيق، لذا لا يحتاج فتح الإرشادات إلى استضافة الموقع.

## بناء APK باستخدام Android Studio
1. فك ضغط المشروع.
2. افتح Android Studio واختر **Open** وحدد مجلد `RABI3_Gaming_Guide_Android`.
3. انتظر انتهاء Gradle Sync. تأكد من تثبيت JDK 17 وAndroid SDK Platform 35 عند الطلب.
4. من القائمة **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. بعد نجاح البناء، يوجد الملف عادة في:
   `app/build/outputs/apk/debug/app-debug.apk`

لا حاجة لتثبيت Android Emulator إذا كان الهدف فقط بناء APK وتجربته على هاتف حقيقي.

## بناء APK تلقائيًا عبر GitHub
يتضمن المشروع ملف GitHub Actions في `.github/workflows/android.yml`.
1. أنشئ مستودعًا جديدًا على GitHub.
2. فك ضغط ZIP على الكمبيوتر، ثم ارفع **كل محتويات المجلد** إلى المستودع، وليس ملف ZIP وحده. تأكد من رفع مجلد `.github` أيضًا.
3. افتح تبويب **Actions**. يمكن أن يبدأ البناء بعد الرفع، أو اختر `Build RABI3 Android APK` ثم **Run workflow**.
4. عند نجاح التشغيل، افتح صفحة التشغيل وانزل إلى **Artifacts**.
5. نزّل `RABI3-Gaming-Guide-APK.zip`، وفك ضغطه للحصول على `app-debug.apk`.

## حدود النسخة الحالية
- طلب الصيانة لا يُرسل إلى شركة الربيع؛ يتم تجهيز ملخص محلي فقط.
- لا توجد لوحة إدارة آمنة أو قاعدة بيانات مشتركة حتى الآن. إضافة إدارة حقيقية تتطلب خادمًا وتسجيل دخول وصلاحيات.
- أسماء الفروع معروضة كإرشاد فقط؛ أضف العناوين ومواعيد العمل ووسائل التواصل الرسمية بعد التحقق.
- يجب مراجعة الإرشادات فنيًا قبل النشر العام.
- ملف APK من نوع `debug` للتجربة والمشاركة المحدودة، وليس إصدارًا موقّعًا للنشر على Google Play.

## بنية المشروع
- `app/src/main/java/.../MainActivity.java` — شاشة التطبيق وWebView.
- `app/src/main/assets/www/` — واجهة الدليل وملفات CSS/JavaScript.
- `app/src/main/res/` — موارد Android.
- `.github/workflows/android.yml` — بناء APK تلقائيًا.
